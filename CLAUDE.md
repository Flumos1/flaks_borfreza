# CLAUDE.md — контекст проєкту для Claude Code

## Що це
Статичний сайт-каталог твердосплавних борфрез (шарошок) у фірмовому стилі FLAKS.
HTML + вбудований CSS + React 18 через CDN з транспіляцією Babel у браузері.
Двомовний UA/RU. Готовий до публікації «як є».

## Головне завдання користувача
Розмістити сайт на GitHub + (за бажанням) увімкнути GitHub Pages. Див. README.md.

## Архітектура
- `index.html` — єдина точка входу, тримає ВЕСЬ CSS у `<style>`.
- React-компоненти лежать у `.jsx`-файлах, підключених `<script type="text/babel">`.
- Глобальні залежності між файлами через `Object.assign(window, {...})`
  (НЕ ES-модулі) — бо Babel-standalone дає кожному скрипту власний scope.
- Порядок підключення скриптів критичний (React→ReactDOM→Babel→tweaks→motion→
  burr-data→burr-shapes→app). Не міняти.

## Дані
`burr-data.jsx` містить масив `PRODUCTS` (81 SKU) і об'єкт `STRINGS` з усіма
рядками інтерфейсу для двох мов. Уся текстівка — там.

## Правила стилю (обов'язково)
- Лише дизайн-система FLAKS: токени в `colors_and_type.css`, кольори/шрифти не вигадувати.
- Помаранчевий акцент `#e85d04` / hover `#ff7c2a`; зелений `#25d366` — тільки WhatsApp.
- Шрифти: Bebas Neue (заголовки, UPPERCASE) + Roboto Condensed (текст).
- Тон копірайту: прямий, «майстровий», звертання на «ти», числа > прикметників.
- Будь-який новий текст — одразу двома мовами (UA + RU) у `STRINGS`.
