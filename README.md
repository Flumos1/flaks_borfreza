## 📋 Для Claude Code — що зробити

Користувач хоче **опублікувати цей сайт на GitHub** і (за бажанням) увімкнути
безкоштовний хостинг GitHub Pages. Сайт — статичний (HTML + CSS + React через CDN),
жодного збирання не потрібно.

### 1. Створити репозиторій і залити файли

```bash
cd flaks-borfrezy
git init
git add .
git commit -m "FLAKS борфрези — сайт-каталог"
git branch -M main
git remote add origin https://github.com/<USERNAME>/flaks-borfrezy.git
git push -u origin main
```

### 2. Увімкнути GitHub Pages

- Repository → **Settings → Pages**
- **Source:** Deploy from a branch
- **Branch:** `main`, folder `/ (root)` → **Save**
- За ~1 хвилину сайт буде на `https://<USERNAME>.github.io/flaks-borfrezy/`

Усі шляхи в проєкті **відносні** (`assets/...`, `app.jsx`, ...), тому Pages
з підпапки працює без правок.

### 3. (Опціонально) Власний домен

Якщо є домен (напр. `flaks.ua`) — додайте файл `CNAME` з доменом у корінь
і пропишіть DNS згідно з інструкцією GitHub Pages.

## ▶️ Локальний запуск

Через `file://` не запрацює (браузер блокує підвантаження `.jsx`).
Підніміть будь-який статичний сервер:

```bash
python3 -m http.server 8000
# відкрийте http://localhost:8000
```

> React + Babel підключаються з CDN і **транспілюються в браузері** —
> зручно для розробки/демо, але додає ~1 с на старті.

## ⚠️ Відоме обмеження — Telegram

Кнопка «Telegram» відкриває бота за посиланням `t.me/<bot>?text=...`, але
**Telegram НЕ підставляє текст замовлення в бота через таке посилання**
(на відміну від WhatsApp та e-mail, які підставляють повністю).

Щоб замовлення реально потрапляло в бота автоматично, потрібен один із варіантів:
1. **Telegram Web App** (кнопка-застосунок усередині бота) — найкращий UX;
2. **Серверний приймач форми** (напр. Cloudflare Worker / Vercel Function),
   що шле повідомлення через Bot API `sendMessage` у ваш чат.

Якщо потрібно — це окреме невелике доопрацювання (бекенд + ключ бота).

## 🚀 (Опціонально) Продакшн-збірка

Для бойового сайту варто прекомпілювати `.jsx`, щоб прибрати Babel із браузера:

- візьміть **Vite** (`npm create vite@latest`, шаблон React),
- перенесіть компоненти з `app.jsx` / `*.jsx` у модулі,
- замініть CDN-скрипти на `import`,
- `npm run build` → статика в `dist/`.

Це прибере залежність від CDN і пришвидшить завантаження. Поточна версія
повністю робоча і без цього кроку.
