# Аудит borfrezy.in.ua

## Короткий путь (по порядку)
1. **Синхронизация — первым делом.** `git fetch; git rev-list --left-right --count origin/main...HEAD`.
   Работа идёт с нескольких машин: локально уже дважды было отставание на 10–15 коммитов. Отстали → `git pull --ff-only`, и только потом ревью.
2. Прошлые отчёты: `AUDIT-*.md`, `ОТЧЁТ-*.md` — раздел «Что требует владельца» = открытые пункты. Не переоткрывать закрытое.
3. Локально: `npm ci` → `npm test` → `npm run build` (prebuild = `npm run seo` с `check:seo`) → `npm audit` (**с dev**: `--omit=dev` скрывает уязвимости Vite/sharp).
4. Детерминизм: после сборки `git status --short` должен быть пуст. Любой дифф в `public/` = недетерминированный генератор или рассинхрон.
5. Прод: `node scripts/check-live.mjs` (160 товарных страниц) и `node scripts/crawl-sitemap.mjs` (все URL sitemap: статус, canonical, hreflang, JSON-LD, редиректы `?lang=`). Выводят только проблемы.
6. Браузер (встроенный): консоль на `/ua/` и товарной странице — нарушения CSP, preload-предупреждения; заголовки — через `fetch(location.href).headers` в `javascript_tool`.
7. Ревью кода по диффу с прошлого аудита: `api/order.js`, `middleware.js`, `public/product-checkout.js`, `src/data/*.js`, `src/App.jsx`, генераторы.
8. Google: `node scripts/merchant-audit.mjs`, `node scripts/gsc-audit.mjs` — нужен `secrets/` (OAuth; есть не на каждой машине → спросить владельца). Без него — скриншоты владельца из GSC/MC.
9. Исправить → `npm run build` + `npm test` + проверка в `npm run preview` (порт 4173) → коммиты по темам → **пуш только с согласия** (main = прод).

## Ловушки (проверено)
- `site:` через WebSearch/Bing/DDG врёт (американская выдача) — индексацию смотреть только в GSC. google.com во встроенном браузере не открывается.
- `main-*.js` на проде — норма (три входа сборки), не признак старого деплоя.
- `/?q=CODE`, `?shape=`, `?sort=` — живые фильтры каталога. Не редиректить. «Ошибка переадресации» в GSC на них — старые июньские данные → «Проверить исправление».
- 32 «Вариант страницы с canonical» в GSC — норма (старые `/borfrezy/…` и `?lang=ru`).
- Слаги товаров в нижнем регистре, пути Vercel чувствительны к регистру.
- Сначала точные URL из GSC «Примеры», потом гипотезы — слепой перебор редиректов не работает.
- `vite preview` + встроенный браузер кэширует старый HTML: добавлять `?r=N` к URL после пересборки.
- Windows: без `.gitattributes` (eol=lf) генераторы давали другой хэш `product-checkout.js?v=` и меняли 240 файлов.
- Misrepresentation в Merchant — доверие к новому аккаунту/домену, а не ФОП/почта. Реквизиты, сроки возврата, тарифы не выдумывать — только данные владельца.
- Решения владельца 2026-10-29: возврат 14 дней, любая причина или брак, почтой, **бесплатно** (`returnFees: FreeReturn`); доставка в MC — единая ставка **90 грн** (тариф НП до 2 кг по Украине с 13.04.2026; сверять при смене тарифов). Сайт, разметка и MC должны совпадать.
- Merchant Center: правка — через Claude in Chrome (вход владельца); шаги мастера правила не перепрыгиваются, только «Продолжить». Новое правило доставки не создавать — редактировать «Нова Пошта». Часовой пояс отсечки в правиле — GMT+1 (не Киев), не меняли.
- `cssPreloadPlugin` в `vite.config.js` не удалять (CLAUDE.md); preload обязан иметь `crossorigin`.

## Проверить (не подтверждено)
- Учитывает ли Google canonical, который JS ставит на `?lang=ru` для ручных страниц (смотреть в GSC после деплоя 2026-10-29).
- `shippingDetails` в Product — на сайте «по тарифам перевозчика», фиксированную сумму не публикуем; добавлять только если сайт начнёт называть цену.
- Rate-limit/идемпотентность `/api/order` (нужно хранилище — Upstash/Vercel KV).
